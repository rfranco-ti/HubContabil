## 📊 Regras Gerais

### Quem Tem Direito
- Todos os empregados com carteira assinada
- Aposentados e pensionistas do INSS
- Trabalhadores avulsos
- Diaristas (com vínculo)

### Parcelas e Prazos 2026
| Parcela | Percentual | Prazo |
|---------|-----------|-------|
| **1ª Parcela (Antecipação)** | 50% do bruto | 01/02 a 30/11 OU junto com férias |
| **2ª Parcela** | 50% - descontos | Até 20/12 |

## 🧮 Cálculos

### 13º Integral
```
13º = Salário Bruto
1ª Parcela = 13º × 50% (sem descontos)
2ª Parcela = 13º × 50% - INSS - IRRF
```

### 13º Proporcional
```
Meses = contar meses com ≥ 15 dias trabalhados no ano
→ Admissão até 15 do mês = conta o mês
→ Demissão após 15 do mês = conta o mês

13º Proporcional = (Salário / 12) × Meses

1ª Parcela = 13º Proporcional × 50% (sem descontos)
2ª Parcela = 13º Proporcional × 50% - INSS - IRRF
```

### Descontos na 2ª Parcela
```
INSS = calcular pela tabela progressiva sobre o valor da 2ª parcela
IRRF = calcular pela tabela progressiva sobre (2ª parcela - INSS - dependentes)
```

### 13º na Rescisão
```
Meses = contar do aniversário do 13º (janeiro) até mês da rescisão
→ Inclui projeção do aviso prévio indenizado

13º Rescisório = (Salário / 12) × Meses
Descontos: INSS e IRRF (na 2ª parcela proporcional)
```

## 📝 Exemplo Completo
```
Salário: R$ 5.000
Admissão: 01/03/2026
Rescisão: 25/10/2026

Meses 13º: Mar(15+) + Abr + Mai + Jun + Jul + Ago + Set + Out(25, ≥15) = 8 meses

13º Proporcional = (5.000 / 12) × 8 = R$ 3.333,33

1ª Parcela = 3.333,33 × 50% = R$ 1.666,67 (sem descontos)
2ª Parcela Bruta = R$ 1.666,67

INSS 2ª parcela:
  Faixa 2: 1.666,67 × 9% = R$ 149,50 (aproximado)
  Base IRRF = 1.666,67 - 149,50 = R$ 1.517,17 → Isento

2ª Parcela Líquida = 1.666,67 - 149,50 = R$ 1.517,17

Total 13º = 1.666,67 + 1.517,17 = R$ 3.183,84
```
