# 🏖️ Férias CLT 2026 - Cálculo Completo

**Última atualização:** 05 de abril de 2026  
**Versão:** 1.0  
**Status:** ✅ Documentado

## ⚖️ Base Legal
| Norma | Dispositivo | Descrição |
|-------|-------------|-----------|
| **CLT, Art. 129** | - | Direito a férias anuais |
| **CLT, Art. 130** | - | Período de férias por faltas |
| **CLT, Art. 134-135** | - | Concessão e gozo |
| **CLT, Art. 137** | - | Férias em dobro |
| **CLT, Art. 142-146** | - | Férias na rescisão |
| **CF/88, Art. 7º, XVII** | - | 1/3 constitucional |

## 📊 Tipos de Férias

### 1. Férias Simples (Gozadas)
```
Férias = Salário
1/3 Constitucional = Salário / 3
Total = Salário + 1/3
```

### 2. Férias Vencidas (Não gozadas no período concessivo)
```
Período concessivo: 12 meses após período aquisitivo
Se empresa não concedeu → férias em DOBRO

Férias em Dobro = Salário × 2
1/3 = (Salário × 2) / 3
Total = (Salário × 2) + 1/3
```

### 3. Férias Proporcionais
```
Meses = contar do início do período aquisitivo até rescisão
→ Mês conta se ≥ 15 dias trabalhados

Férias Prop = (Salário / 12) × Meses
1/3 = Férias Prop / 3
Total = Férias Prop + 1/3
```

### 4. Férias Indenizadas (na rescisão)
```
Mesmo cálculo das proporcionais
Inclui 1/3 constitucional
```

### 5. Abono Pecuniário (venda de 1/3 das férias)
```
Abono = (Salário / 3) + (Salário / 3 / 3)
      = (Salário / 3) × (1 + 1/3)
      = Salário × 4/9
```

## 📝 Impacto das Faltas (Art. 130 CLT)

| Faltas no Período Aquisitivo | Dias de Férias |
|------------------------------|----------------|
| Até 5 faltas | 30 dias |
| 6 a 14 faltas | 24 dias |
| 15 a 23 faltas | 18 dias |
| 24 a 32 faltas | 12 dias |
| Mais de 32 faltas | Perde direito |

## 📝 Exemplo Completo
```
Salário: R$ 4.000
Férias vencidas: Sim (1 período)
Férias proporcionais: 7/12 avos
Abono pecuniário: Não

1. Férias Vencidas:
   Valor = 4.000 × 2 = R$ 8.000
   1/3 = 8.000 / 3 = R$ 2.666,67
   Total Vencidas = R$ 10.666,67

2. Férias Proporcionais:
   Valor = (4.000 / 12) × 7 = R$ 2.333,33
   1/3 = 2.333,33 / 3 = R$ 777,78
   Total Proporcionais = R$ 3.111,11

Total Férias = R$ 13.777,78
```
