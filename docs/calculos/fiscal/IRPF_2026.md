## 📖 Visão Geral

O IRPF é o imposto sobre renda das pessoas físicas. Calculado progressivamente sobre rendimentos tributáveis, com deduções legais.

## 🧮 Cálculo Completo

### Passo 1: Rendimentos Tributáveis
```
- Salários e pró-labore
- Aluguéis recebidos
- Rendimentos de trabalho autônomo
- Pensão alimentícia recebida
- Aposentadoria e pensão
```

### Passo 2: Deduções Permitidas
```
- INSS (integral)
- Dependentes (R$ 189,59/mês cada)
- Despesas médicas e odontológicas (ilimitado)
- Despesas de instrução (R$ 3.561,50/ano por pessoa)
- Pensão alimentícia judicial
- Contribuição a PGBL (até 12% da renda bruta)
- Desconto simplificado (R$ 7.286,40/ano - opcional)
```

### Passo 3: Base de Cálculo
```
Base = Rendimentos Tributáveis - Deduções

Ou com desconto simplificado:
Base = Rendimentos Tributáveis - R$ 7.286,40
(usa-se o que for mais vantajoso)
```

### Passo 4: Cálculo do Imposto
```
IRPF = (Base × Alíquota da Faixa) - Parcela a Deduzir

Exemplo: Renda anual R$ 60.000, com 2 dependentes e INSS R$ 5.000

Opção 1 (deduções legais):
  Base = 60.000 - 5.000 - (2 × 2.275,08) = 50.449,84
  Faixa 4: 45.012,61 – 55.976,16
  IRPF = (50.449,84 × 22,5%) - 7.953,24 = R$ 3.403,20

Opção 2 (simplificado):
  Base = 60.000 - 7.286,40 = 52.713,60
  Faixa 4: IRPF = (52.713,60 × 22,5%) - 7.953,24 = R$ 3.906,60

→ Opção 1 mais vantajosa: R$ 3.403,20
```

## 📝 Carnê-Leão

Para rendimentos recebidos de PF ou do exterior:
- **Obrigação:** Recolher mensalmente via DARF
- **Prazo:** Último dia útil do mês seguinte
- **Base:** Rendimentos do mês - deduções
- **Alíquotas:** Mesma tabela progressiva

## 📋 Declaração Anual
