# 💰 PIS/COFINS Não-Cumulativo 2026

**Última atualização:** 05 de abril de 2026  
**Versão:** 1.0  
**Status:** ✅ Documentado

| Norma | Descrição |
|-------|-----------|
| **Lei 10.637/2002** | PIS não-cumulativo |

| **EC 103/2019** | Reforma previdenciária (impacto) |
| **STF Tema 1.162** | Exclusão ICMS da base |

## 📊 Alíquotas 2026 (Não-Cumulativo / Lucro Real)
| Tributo | Alíquota |
|---------|----------|
| **PIS** | 1,65% |
| **COFINS** | 7,6% |
| **Total** | **9,25%** |

## 🧮 Cálculo

### Débito
```
PIS Débito = Receita Bruta (excl. ICMS) × 1,65%
COFINS Débito = Receita Bruta (excl. ICMS) × 7,6%
```

### Créditos Permitidos
```
Insumos, matéria-prima, produtos em processo
Embalagens, energia elétrica, aluguéis de prédios/máquinas
Depreciação e amortização de bens
Serviços de terceiros (pessoas jurídicas)
Fretes sobre vendas
Retornos de valores pagos

Crédito = Base de Crédito × Alíquota (1,65% ou 7,6%)
```

### Líquido a Pagar
```
PIS Líquido = PIS Débito - PIS Créditos
COFINS Líquido = COFINS Débito - COFINS Créditos
```

## 📝 Exemplo
```
Receita Bruta: R$ 500.000
ICMS destacado: R$ 90.000
Base PIS/COFINS: R$ 410.000

Débitos:
PIS = 410.000 × 1,65% = R$ 6.765
COFINS = 410.000 × 7,6% = R$ 31.160

Créditos (insumos R$ 200.000):
PIS Cr = 200.000 × 1,65% = R$ 3.300
COFINS Cr = 200.000 × 7,6% = R$ 15.200

Líquido:
PIS = 6.765 - 3.300 = R$ 3.465
COFINS = 31.160 - 15.200 = R$ 15.960
Total: R$ 19.425
```
