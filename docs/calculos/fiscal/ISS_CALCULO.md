# 🏢 ISS 2026 - Cálculo Completo

**Última atualização:** 05 de abril de 2026  
**Versão:** 1.0  
**Status:** ✅ Documentado

## ⚖️ Base Legal
| Norma | Descrição |
|-------|-----------|
| **LC 116/2003** | Lista de 42 serviços, regras gerais |
| **CF/88, Art. 156, III** | Base constitucional |
| **Leis Municipais** | Alíquotas e regulamentação local |

## 📊 Alíquotas
- **Mínima:** 2% (LC 116/2003)
- **Máxima:** 5% (LC 116/2003)
- **São Paulo 2026:** 2% a 5% conforme serviço
- **MEI:** Valor fixo mensal (não incide ISS adicional)

## 🧮 Cálculo

### ISS Normal
```
ISS = Valor do Serviço × Alíquota Municipal
```

### ISS com Retenção na Fonte
```
Aplicável para serviços de:
- Limpeza e conservação
- Vigilância
- Locação de mão de obra
- Construção civil
- Intermediação de negócios

ISS Retido = Valor Serviço × Alíquota (recolhido pelo tomador)
```

### ISS Construção Civil (Dedução Materiais)
```
Base ISS = Valor Total - Materiais (se atendidos requisitos)
  Requisitos:
  - Materiais agregados permanentemente
  - Produzidos pelo prestador fora da obra
  - Incluídos no contrato

ISS = (Valor - Materiais) × Alíquota
```

## 📋 Regimes de Apuração

- **Por nota:** Conforme legislação municipal
