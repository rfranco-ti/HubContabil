## 🧮 Cálculo

### Depreciação Linear (Método Padrão)
```
Depreciação Anual = (Custo Aquisição - Valor Residual) / Vida Útil

Depreciação Mensal = Depreciação Anual / 12

Taxa Mensal = Taxa Anual / 12
```

### Exemplo: Veículo
```
Custo: R$ 120.000
Valor Residual: R$ 20.000 (estimado)
Vida Útil: 5 anos

Depreciação Anual = (120.000 - 20.000) / 5 = R$ 20.000/ano
Depreciação Mensal = 20.000 / 12 = R$ 1.666,67/mês

Taxa Anual = 100.000 / 5 anos = 20%
```

### Depreciação Acelerada
```
Fiscal: apenas com incentivo fiscal ou autorização RFB
Contábil: quando vida útil contábil < vida útil fiscal
→ Justificar com base técnica
```

## 📝 Contabilização

### Lançamento Mensal
```
D - Despesa com Depreciação (Resultado)
C - Depreciação Acumulada (Retificadora do Ativo)

Valor: Depreciação Mensal calculada
```

### Baixa do Bem
```
D - Depreciação Acumulada (valor total acumulado)
D - Perda na Alienação (se valor venda < valor contábil)
C - Ativo Imobilizado (custo original)
C - Ganho na Alienação (se valor venda > valor contábil)
```

## 📝 Diferença Contábil vs Fiscal

```
Contábil: vida útil estimada pela empresa (CPC 27)
Fiscal: vida útil da tabela IN RFB 1.700/2017

Se diferente → controle no LALUR (adição/exclusão)
```
