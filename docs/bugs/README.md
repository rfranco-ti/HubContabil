# 🐛 Documentação de Bugs

**Diretório:** `docs/bugs/`

---

## 📋 Propósito

Este diretório documenta **TODOS** os bugs encontrados no projeto, incluindo:
- Descrição detalhada do bug
- Causa raiz identificada
- Solução aplicada
- Lições aprendidas
- Prevenção futura

---

## 📁 Formato dos Arquivos

Cada bug deve ser documentado em arquivo com nome:
```
AAAAMMDD_HHMM_NOME_BUG.md
```

**Exemplo:** `20260405_1430_error_prisma_relation.md`

---

## ✅ Checklist ao Documentar Bug

- [ ] Criar arquivo com formato `AAAAMMDD_HHMM_NOME.md`
- [ ] Preencher template completo
- [ ] Incluir código antes/depois se aplicável
- [ ] Listar todos os arquivos modificados
- [ ] Documentar pesquisa realizada
- [ ] Atualizar `docs/CHANGELOG.md`
- [ ] Notificar usuário
